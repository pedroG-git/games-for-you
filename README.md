# Joana's Games

An offline Android app with a collection of small games:

- **Bus da Joana**: a bus-jam puzzle with a Bob's Burgers theme
- **Paciência da Joana**: Klondike solitaire in 3D (pt-PT)
- **Café da Joana**: a 3D vegan-café idle game with Pedro, Meme and Mimi (pt)

This is a non-commercial fan project and isn't affiliated with Bob's Burgers or its owners.

## Install on the phone

1. On the phone, open **https://pedrog-git.github.io/joanas-games/** and tap **Download for Android**.
2. Open the download. Android asks you to allow installs from your browser the first time. Allow it, then tap **Install**.
3. After that, the app works fully offline. Progress is saved on the phone.

**Updates:** when the phone is online, the home screen shows *"Version X is ready!"*. Tap **Update**, open the download, and tap **Install**. Progress is kept.

## How it's built

- `www/` contains the app itself, written in plain HTML/JS/CSS.
  - `index.html`, `hub.js`, `hub.css`: the home screen with the game tiles and the update check.
  - `games.js`: the list of games on the home screen.
  - `games/bus/`, `games/paciencia/`, `games/cafe/`: the games.
  - `shared/`: things all games can use. This includes the fonts and Three.js (`shared/vendor/three/`), which Paciência and Café share.
- `android/`: the Android project generated by [Capacitor](https://capacitorjs.com), which wraps `www/` in an app.
- `assets/`: the app icon and splash screen. Sources are in `assets/src/`. Regenerate with `npx @capacitor/assets generate --android --iconBackgroundColor '#f3e6c9' --splashBackgroundColor '#f3e6c9'`.
- `.github/workflows/release.yml`: pushing a tag like `v1.2.3` makes GitHub build and sign the APK and publish it as a release.

## Working on it

```sh
npm install
npm run serve      # play in a browser at http://localhost:3002
npm test           # checks the bus levels are valid and solvable
```

### Adding a game

1. Put it in `www/games/<name>/`, with its own `index.html`. Use relative paths only, and nothing that needs the internet.
2. Add a line to `www/games.js`.
3. Add a `← All games` link back to `../../index.html`.
4. Save progress with `localStorage`, using a key unique to the game.

### Releasing an update

```sh
npm version patch   # or minor / major: bumps package.json, commits, tags
git push --follow-tags
```

GitHub Actions builds the APK. A few minutes later the update appears on the phone.

## Signing key

Release APKs are signed with a key that lives **outside** this repo, in `../JoanasGames-signing/`, and in the repo secrets `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD` and `KEY_ALIAS`.
Keep a backup of it. If the key is lost, updates can't be installed over the existing app.

## Download page
